# Когнитив.Про — база данных (этап Б)

Папка для установки базы на хост (sprinthost, MySQL 8).

## Файлы

| Файл | Назначение |
|---|---|
| `schema.sql` | Схема: 11 таблиц + 12 курсов + настройки. Импортируется через phpMyAdmin |
| `config.php` | Параметры подключения к базе (заполнить из панели хостинга) |
| `install.php` | Разовый скрипт: создаёт аккаунты и уроки, может сам накатить схему |

## Порядок установки

1. **Панель sprinthost → «Базы данных MySQL»** — создайте базу и пользователя, запишите имя базы, пользователя и пароль.
2. **phpMyAdmin** (кнопка в панели рядом с базой) — выберите базу слева, вкладка **«Импорт»** → загрузите `schema.sql` → «Вперёд».
3. Отредактируйте `config.php` (host, имя базы, пользователь, пароль).
4. Загрузите `config.php` и `install.php` в `public_html/`.
5. Откройте `https://ваш-домен/install.php` — появятся отчёты «✓» о созданных аккаунтах и уроках.
6. **Удалите `install.php` и `config.php` с хоста** — они содержат доступ к базе.

## Что создаётся

- **Аккаунты**: `admin` / `school` / `bichurin`, пароль у всех `1234567890` (хранится хэшем).
- **Уроки**: у всех 12 курсов, включая блоки логики (24 блока + тест у школьных курсов).
- **Настройки**: демо-период 3 дня, лимит 3 блока логики в день, пустой QR (заполнит админ).

## Таблицы

`kgn_users` (вход и роли) · `kgn_students` (профили, очки, звёзды, дни занятий) ·
`kgn_courses` (цены, сроки, публикация) · `kgn_lessons` · `kgn_progress` (пройденные уроки) ·
`kgn_access` (доступ со сроком) · `kgn_payments` · `kgn_promotions` + `kgn_promotion_courses` (акции) ·
`kgn_settings` · `kgn_login_attempts` (защита от подбора)
