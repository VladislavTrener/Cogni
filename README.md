## Запуск

1. Установите [Node.js LTS](https://nodejs.org) (один раз).
2. Откройте терминал в папке проекта и выполните:

```
npm install
npm run dev
```

3. Откройте в браузере **http://localhost:5173** — готово.

Продакшен-сборка: `npm run build` (результат в `dist/`), локальный просмотр: `npm run preview`.

## Что внутри платформы

- **Роли**: ученик, преподаватель, администратор. Вход по логину и паролю,
  регистрация (имя, телефон, e-mail, оферта), блокировка после 3 неверных попыток.
- **Демо-доступ 3 дня** для новых учеников, далее — платно. Админ может
  приостановить/возобновить пользователя (вход блокируется).
- **Оплата на самозанятого** (карта / СБП) с назначением «Когнитив.ПРО курс …»,
  доступ на срок курса (у «Тренировки умножения» — 1500 ₽ / 3 месяца).
- **Акции**: админ собирает наборы курсов (вручную или целое направление),
  скидка в % или фикс. цена; ученик видит акции при покупке.
- **5 направлений**: СЧЁТ, ПАМЯТЬ, ЛОГИКА, ЗНАНИЕ, МЕНТАЛЬНОЕ ЗДОРОВЬЕ.
- **Тренажёры**: умножение (коробки Лейтнера, тетрадь, космополёт),
  сложение (счёт до 20, интервалы, космолёт), вычитание (от 10, от 20, микс),
  N-back, последовательности, тест Струпа (4×4–10×10, таблицы Горбова),
  квест на 100 задач, логика 150 + 235 + 235 задач (смешанные блоки).
- **Геймификация**: очки, звёзды за дни занятий (×1/×2/×3 по неделям серии),
  значки, Доска почёта, звуки. Лимит: не больше 3 блоков логики в день.
- **Учитель**: отметки прогресса, статусы курсов (read-only), ученики с
  сортировкой по имени и оплате.
- **Администратор**: KPI, цены и сроки курсов, демо-период, QR-код оплаты,
  акции, платежи, приостановка и удаление учеников, смена паролей.

Все данные — локально в браузере (демо). Кнопка «Сбросить демо» возвращает исходные данные.

## Деплой на хост

Сайт — статическая сборка: после `npm run build` всё лежит в папке `dist/`
(`index.html` + `assets/`). Node.js, PHP и база данных на сервере **не нужны**.

### Вариант А — бесплатно и за 2 минуты (Netlify Drop)

1. Откройте `app.netlify.com/drop` (нужен бесплатный аккаунт).
2. Перетащите папку `dist/` в окно браузера.
3. Получите ссылку `https://имя.netlify.app`; свой домен подключается в настройках.

Аналоги: GitHub Pages, Cloudflare Pages, Vercel — тоже бесплатно.

### Вариант Б — обычный виртуальный хостинг (Beget, Timeweb, Reg.ru)

1. В панели хостинга откройте «Файловый менеджер» или подключитесь по FTP (FileZilla).
2. Перейдите в корневую папку сайта (обычно `public_html/`).
3. Загрузите **содержимое** папки `dist/` — файл `index.html` и папку `assets/`.
4. Включите бесплатный SSL (Let's Encrypt) в панели — сайт откроется по https.

### Вариант В — свой VPS с nginx

```bash
sudo apt update && sudo apt install -y nginx
sudo mkdir -p /var/www/kognitiv
# с компьютера:
scp -r dist/* user@сервер:/var/www/kognitiv/
```

Конфиг `/etc/nginx/sites-available/kognitiv`:

```nginx
server {
    listen 80;
    server_name ваш-домен.ru;
    root /var/www/kognitiv;
    index index.html;
    location / { try_files $uri $uri/ /index.html; }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/kognitiv /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d ваш-домен.ru    # бесплатный HTTPS
```

### Важно про данные

Сейчас данные (ученики, прогресс, покупки, акции) хранятся в localStorage
браузера каждого посетителя — это демо-режим, идеальный для показа и тестов.
Для настоящей школы следующим этапом добавляется серверная часть:
база пользователей и прогресса, серверная авторизация, приём платежей
(самозанятому — ЮKassa / Тинькофф) с автовыдачей доступа.
Вся работа с данными изолирована в `src/store.tsx` — он и заменяется на API.
