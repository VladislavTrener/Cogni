## Запуск

1. Установите [Node.js LTS](https://nodejs.org) (один раз).
2. Откройте терминал в папке проекта и выполните:

```
npm install
npm run dev
```

3. Откройте в браузере **http://localhost:5173** — готово.

Продакшен-сборка: `npm run build` (результат в `dist/`), локальный просмотр: `npm run preview`.

## Что внутри платформы

- **Роли**: ученик, преподаватель, администратор (вход в один клик, демо).
- **Демо-доступ 3 дня** для новых учеников, далее — платно.
- **Оплата на самозанятого** (карта / СБП) с назначением «Курс „…" — Когнитив.Про»,
  доступ на срок курса (у «Тренировки умножения» — 1500 ₽ / 3 месяца).
- **9 тренажёров**: 3 на умножение (коробки Лейтнера, тетрадь, космополёт),
  3 на сложение (счёт до 20, интервалы, космолёт), N-back, последовательности,
  квест на 100 задач. Очки, серии, значки, Доска почёта, звуки.
- **Учитель**: отметки прогресса, статусы курсов (read-only), ученики с
  сортировкой по имени и оплате.
- **Администратор**: KPI, цены и сроки курсов, демо-период, платежи,
  удаление учеников, смена паролей.

Все данные — локально в браузере (демо). Кнопка «Сбросить демо» возвращает исходные данные.
